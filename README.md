# Estatuto e Governança — Madeira Hacker Club (MHC)

Repositório oficial de documentos de governança do **Madeira Hacker Club (MHC)**, em Porto Velho, RO.

## Documentos

- **[Código de Conduta (V1.0)](./CODE_OF_CONDUCT.md)** — Princípios éticos, comportamentos esperados e inaceitáveis, relato de incidentes e o Anexo 0 (Protocolo "Jardim de Infância").
- *Estatuto Social, Regimento Interno e Atas* — Serão adicionados aqui conforme aprovação pela comunidade.

## Como Contribuir

Propostas de melhoria, correções e atualizações devem ser enviadas via **Pull Request** ou discutidas previamente via **Issues**.

Ao contribuir, procure manter o texto claro, em Markdown padrão e alinhado aos pilares de tecnologia livre, respeito mútuo e transparência do clube.
